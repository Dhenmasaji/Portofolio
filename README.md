# Dhenmas Aji — Personal Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — dark navy theme, layout, responsive styles, project mockups
- `script.js` — mobile navigation and placeholder-contact behavior

## Run in VS Code
1. Extract this ZIP file.
2. Open the extracted `portfolio_website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension in VS Code.
4. If using Live Server, right-click `index.html` and select **Open with Live Server**.

The Google Fonts import requires an internet connection. The page still works if the font service is unavailable.

## Personalize before publishing
1. In `index.html`, check the name, education, work experience, project descriptions, and achievements.
2. Replace the email, LinkedIn, and GitHub placeholders in the Contact section with your real URLs/details.
3. Add verified project repository/demo links and screenshots only when available.
4. Confirm all wording is accurate before sharing with recruiters. Do not publish confidential BNI or employer materials.
5. If you want a downloadable CV button, add your own CV file and link only after the file is ready.

## Notes
- No contact details, repositories, live demo links, or certifications have been invented.
- Project cards are visual summaries and do not claim that a public demo is live.
- Skill names indicate areas/tools discussed, not formal certifications.
